# Yarn discovery image production

Generated with the built-in image generation tool. These are illustrative yarn styling photos, not manufacturer product photos. The UI labels them as generated styling images.

Project assets:
- public/assets/yarn/ivory-wool-styling.webp
- public/assets/yarn/sage-merino-styling.webp

The original generated images were copied into the project and optimized to WebP for web delivery without changing their content.

## Ivory wool prompt

Use case: product-mockup. Asset type: premium yarn discovery website editorial photograph. Create a photorealistic still life of ivory and warm oatmeal wool yarn skeins, a small knitted swatch and wooden knitting needles on warm natural linen, soft morning window light, tactile wool fibers, elegant Korean knitting boutique art direction, quiet minimal composition. Landscape 3:2, all key objects in central area with breathing room. This is an unbranded illustrative yarn styling photograph, not a photo of any named manufacturer's real product. No text, no packaging labels, no logos, no watermark, no people. Muted cream, oatmeal and wood tones. High quality natural texture.

## Sage merino prompt

Use case: product-mockup. Asset type: premium yarn discovery website editorial photograph matching a warm minimalist knitting boutique. Create a photorealistic still life of sage green and pale grey-green merino-style wool yarn skeins, a soft knitted swatch and understated wooden knitting needles on warm ivory linen. Soft diffused morning window light, delicate wool fibers, calm premium studio styling. Landscape 3:2 with central composition, generous breathing room. This is an unbranded illustrative yarn styling photograph, not a photo of any named manufacturer's real product. No text, no labels, no logos, no watermark, no people. Color palette sage green, ivory, muted oak.
