# 이미지·문의·필수 도안 정보

- 이미지 관리: 주소 복사 옆 삭제, 페이지 단위 최대 25장 일괄 삭제, 휴지통 복구. 관리자 인증 API에서 현재 DB에 등록된 이미지 키만 처리한다. 삭제는 선택 목록의 숨김 처리이며, 기존 상품·비공개 테스트룸·등록기록·원본 파일을 변경하지 않는다. 이미지 원본 URL은 계속 작동한다. 공용 이미지 선택기에서도 휴지통 항목을 제외한다.
- 문의·신고: 관리자 알림·공지 다음 메뉴, 회원 MY의 문의·신고. 회원은 자신의 접수와 답변만 조회한다. 관리자는 유형·상태·회원·제목·연결 주소·번호로 검색하고 답변, 담당자, 내부 메모, 처리 이력을 저장한다. 버전 충돌을 검증한다. 내부 메모는 회원 응답과 알림에서 제외한다. 답변 알림은 기존 알림함으로 연결된다. 신고 대상 제재는 관련 콘텐츠 관리 화면에서 별도 처리한다.
- 첨부: 최대 3장, 장당 200,000바이트 미만, 브라우저 압축 후 서버에서 실제 이미지 형식 재검증. 문의 정보와 함께 비공개 저장한다.
- 도안 필수 9개: 작품 분류, 뜨개 종류, 난이도, 제공 언어, 사이즈, 사용 실, 실 소요량, 사용 바늘, 게이지. 기본 정보 화면에 모두 표시한다. 누락 시 난이도 3/언어 한국어는 기본값으로 명시하고, 수치·재료 등은 확인 필요로 표시한다. 분류 미확인은 기타/미분류로 관리한다. 실제 제작 수치를 추측하지 않는다.
- PDF 전체를 항상 분석에 전달한다. 첫 페이지 이미지는 보조 자료로 추가한다. 필드별 원문 페이지 근거를 보존하며 첫 페이지가 본문의 상세 제작 정보를 덮어쓰지 않는다. 재분석은 직접 수정한 값을 유지한다. PDF 분석 실패 후 저장된 원본으로 재시도·직접 작성할 수 있다.
- 확인·수정 시 출처와 확인 여부를 작품 및 새 등록기록에 보존한다. 기존 기록은 수정하지 않는다. 관리자 도안 관리의 확인 필요 필터는 필수 9개와 기본값을 집계한다.
- 추가 저장소: schema-only migration 0011의 image_library_trash 및 support_tickets. 호스팅 배포 과정에서 적용한다.
- 검증: `node --test tests/*.test.mjs`.
